# Каталог анимаций и статус согласования

Это **живой реестр**, отдельный от исходников. Новые кадры утверждаются в чате по блокам.
Документ не означает, что перечисленные предложения уже внедрены.

## Статусы

- **КОНТРАКТ**: пользователь утвердил правило или конкретный кадр; менять без согласования нельзя.
- **НАСЛЕДИЕ**: есть в v0.4.1, но по виду/времени ещё не согласовано.
- **ПРЕДЛОЖЕНИЕ**: пример для обсуждения; не кодировать до решения.

## Общие требования (КОНТРАКТ)

- Сохраняется узнаваемый компактный силуэт `(づ｡◕‿‿◕｡)づ` и ширина скобок.
- Анимации заранее прорисованы и строго детерминированы; никакой автоматической подгонки ширины.
- Эмоции не вырезать ради «простоты»: улыбка `(づ｡>‿‿<｡)づ` и удивление `(づ｡0‿‿0｡)づ` обязательны (символ **ноль 0**, а не O).
- Взгляд вправо = `(づ｡◔‿‿◔｡)づ`: **оба** глаза синхронно смотрят вправо. Отводит взгляд, несколько раз смотрит и возвращается в базу.
- Выбирать **сценарии** из перемешанного цикла без повторов внутри одного цикла, а не каждый раз независимо из общего набора.
- Музыкальный хвост = **старый разворот спиной**, не точка справа. Исторические кадры из `4fc9d30`:
  `ᕦ(   ●   )ᕤ` → `ᕤ(  ●    )ᕦ` → `ᕦ(    ●  )ᕤ`; рисунок перехода и тайминги ещё не утверждены.
- Typing руками пользователю нравится. Сохранить быстрый отклик.
- Matrix-эффект отдельно от сетки питомца: **две плотно прилегающие колонки**, символы поднимаются снизу от печатающего питомца до уровня часов, исчезают вверх; жирнее, читабельнее, каждый новый символ по нажатии.
- Толщина линий питомца должна заметно вырасти без изменения его геометрии. Не менять размер тела вместо увеличения толщины.

## Typing (НАСЛЕДИЕ + КОНТРАКТ)

Сохраняем быстрые реакции лапами (нынешние ID 13/14/15), но требуется согласовать визуальный Matrix-поток. Не смешивать его геометрию с анимациями лица.
