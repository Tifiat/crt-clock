# Каталог анимаций CRT Clock v0.6.4

Обновлено: 4 ноября 2026. Исторический набор ID и обычное лицо сохранены. Источник рисунков — утверждённый пользователем полный набор F/H/I/M/B.

**Статус реализации:** первоначальные рисунки F/H/B и исторические ID 0–38 сохранены. Изменения v0.5.7: общая скорость Idle/Music, ровный музыкальный ритм, базовый groove между танцами, три новых танца. Изменения v0.5.8: спокойный рот в groove, постоянно поднимающиеся векторные ноты во время музыки, возобновление прерванных танцев и запрет соседнего повтора между циклами. Изменения v0.5.9: 14 Idle-действий, редкие прогулка и возвращение с подарком, мягкие анимированные черточки и дыхание между действиями, шесть музыкальных нот и более спокойные музыкальные подмигивания. Изменения v0.6.0: 5 независимых gift-финалов, исчезновение с паузой и возвращение слева направо, лицом по ходу движения, лёгкая/комичная/сильная грусть с раздельной высотой глаз/рта, последовательные слёзы, зрелищный векторный взрыв и плотный поток музыкальных нот справа вместо нот над головой. Оценка читаемости на реальном XFCE остаётся обязательной.

## Неприкосновенные правила

- Референс `(づ｡◕‿‿◕｡)づ`. Компактность, положение скобок и лица сохраняются для всех фронтальных поз. Не менять отдельно размер в конкретных кадрах.
- Выражения/лапки/сценарии — **заранее заданные**, один ID = один набор символов/смещений; только выбор сценариев перемешанными циклами может быть случайным.
- Цифра `0` в удивлении, не `O`. Взгляд вправо: **оба глаза** `◔`.
- Моргающий или радостный персонаж может сохранять лицо `(づ｡>‿‿<｡)づ`, `(づ｡0‿‿0｡)づ`, даже если Unicode-глифы визуально сложные.
- Толщину линий менять отдельно от ширины тела. Фактическую ширину / качество глифов проверять на целевом шрифте и после перспективы.
- Музыкальная попа — **поворот спиной**, хвост находится внутри скобок. Не заменять точкой у фронтального персонажа.
- Matrix-поток не использует ячейки питомца, не считывает настоящие клавиши. Две колонки с прилегающими символами движутся снизу вверх и гаснут у часов.

## Idle: 15 действий (v0.6.3)

Продолжительность ниже дана при **100% скорости движений**. Для быстрого
ползунка (например, 146%) сокращаются жесты и шаги, но не длительность
кадров `hold(...)`: взгляды, сон, пауза ухода, полёт и плач читаются независимо
от темпа движения рук.

| ID | C++ имя | Время при 100% | Смысл и изменения |
|---|---|---:|---|
| I01 | Blink | 2,66 с | Прежнее короткое моргание, без изменений |
| I02 | Peek | 3,95 с | Один взгляд в сторону на 2,05 с → обратно в ожидание |
| I03 | Smile | 4,8 с | Поджимает губы, затем держит весёлое лицо |
| I04 | Surprise | 4,79 с | Глаза «0» остаются открыты 1,75 с; есть вторая эмоция |
| I05 | Smug | 5,75 с | Самодовольные глаза держатся 1,75/1,6 с |
| I06 | Shy | 4,85 с | Одна выдержка с «домиками» на 3 с, короткий румянец у щёк и лёгкий поклон; затем обратно в Idle |
| I07 | Sleepy | 9,21 с | Два длинных сна по 3,4 и 3,2 с с коротким просыпанием |
| I08 | Confused | 5,45 с | Недоумение заметно дольше, без мельтешения |
| I09 | Greeting | 5,6 с | Четыре взмаха лапой и лёгкое качание тела |
| I10 | Fidget | 5,97 с | Восемь активных переключений лап с небольшим перемещением |
| I11 | Celebrate | 8 с | Радуется несколькими циклами, не замедляя движения |
| I12 | Indignant | 6 с | Удивление → одно долгое негодование `ಠ` → усталый взгляд → Idle; без повторных переключений |
| I13 | Patrol | 7,36 с | Равномерная ходьба по холсту, без остановок на краях; зеркальный разворот, покачивание корпуса ±3px; убрана компенсацией «дёрготня» 9px |
| I14 | Fetch | Зависит от подарка | Уход спиной → отсутствие 3,3 с → **полностью из-за левого края** входит подарок, следом питомец → один из 5 финалов; ожидание сопровождается дыханием |

| I15 | WinkLeftRight | 3,27 с | Только в Idle: одна короткая F09 (правый глаз), затем одна F10 (левый), с паузой между ними |

Между завершёнными Idle-историями 7,5–16 с обычного ожидания. Сам питомец
при этом постоянно едва заметно дышит (сдвиг ±1 px). Полосок у неподвижного
персонажа нет, они остаются только обозначением настоящего движения/эффектов.

**Patrol:** `Frame` несёт `moveFrom/moveTo` на весь силуэт. Крайние
смещения −125..+160px. Горизонтальная скорость постоянна через границы
шагов, без остановок в разворотах; каждый шаг даёт мягкий вертикальный
подскок около −3px. Зеркалирование касается только питомца. Исторические
смещения поз шагов ±9px компенсируются, поэтому переходы ног не сдвигают
всё тело. Сетка 10×31px неизменна.

**Fetch:** при уходе спиной рисуется хвост с кончиком. Возвращение
начинается при смещении −420px, когда и подарок, и тело ещё скрыты; при
переходе вправо подарок (чуть впереди лапы) выходит первым. Вся четвёрка
кадров `Carry` интерполирует одинаковое смещение персонажа и предмета.
Во время следующих статичных кадров `Present`, `Charge`, `Pulse`,
полёта и плача питомец продолжает едва заметно дышать.

## Music: 9 действий и базовое покачивание (v0.6.3)

- При воспроизведении MPRIS: **Groove** (8 кадров, 2,24 с) → один случайный танец → Groove → следующий танец.
- Groove: F00 → NodDown → NodUp → F00 → NodDown → NodUp → F00 → F00. Рот остаётся нейтральным: `F17` больше не мелькает по два раза каждый цикл.
- **Каждый кадр каждого музыкального сценария длится 280 мс** при скорости 100%; даже повороты спиной идут под тот же ритм.
- Ни один из 9 танцев не повторяется в пределах цикла `ShuffleBag`; после исчерпания порядок перемешивается заново. Один и тот же танец не может идти подряд даже через границу двух циклов. Печатание прерывает танец, но недоигранное действие будет показано заново перед выбором следующего, без потери позиции в очереди.
- Переходы полностью детерминированы, рандомизирован только порядок действий, а не набор поз и задержек.

| ID | C++ имя | Время при 100% | Изменение v0.6.2 |
|---|---|---:|---|
| M01 | HeadNod | 6,72 с | 24 доли, кивание длится на несколько секунд дольше |
| M02 | TailWag | 5,04 с | 18 долей, добавлены всего несколько движений хвоста |
| M03 | HandGroove | 5,04 с | 18 долей, ±6 px плавного перемещения всего тела |
| M04 | Bounce | 4,48 с | 16 долей; высота прыжков прежняя |
| M05 | Sway | 5,04 с | 18 долей; маленький след только с противоположной стороны раскачивания |
| M06 | HappyDance | 5,04 с | 18 долей, повторяющиеся движения лап и смех |
| M07 | BigDance | 5,04 с | 18 долей, повторяющиеся подпрыгивания и лапки |
| M08 | EyesClosedNotes | 5,04 с | 18 долей; закрытые глаза сохраняются |
| M09 | SideStep | 4,48 с | 16 долей, несколько дополнительных шагов |

Все перечисленные кадры по-прежнему длятся **280 мс при скорости 100%**,
а обычный Groove между танцами остаётся ровно 8 кадров и 2,24 с.
При 146% сами музыкальные движения быстрее; сцена дольше за счёт
дополнительных повторов, а не замедления акцентов.

Смещения `NodDown/NodUp` теперь ±5px, `SwayLeft/Right` ±8px, `BounceUp/Down` ±6px. Новые `StepLeft/Right` ±9px сочетают движение корпуса и лап. Все смещения константные, ширина и положение ячеек не пересчитываются.

**Музыкальный поток v0.6.0:** вместо знаков над головой три плотных векторных колонки по x=390/413/436px, вертикальный шаг 18px, у средней колонки смещение на 11px (шахматный порядок). Вертикальный шаг 22px и плавное затухание возле y=222, как у Matrix. Символы строятся геометрией Qt, без фолбэков Unicode. Поток живёт только при Playing и отсутствии Typing; колонки печати по-прежнему имеют приоритет.

**Ползунок скорости:** `pet/autonomous_speed` = 50–180%, по умолчанию 100%. Он меняет интервалы *жестов* Idle и Music, но не паузы Idle и не `hold`-кадры и фронтальный JoyTail. Не затрагивает `Typing` (115 мс), `MatrixRain`, проверку MPRIS и эффекты CRT.

## Автоматический фронтальный хвост (v0.5.2)

- `src/pet_tail.hpp` проверяет **все позы**, включая Music и Idle, на одновременные радостные глаза `><`. При первом появлении `><` **две итерации анимации по 40 мс** хвост отсутствует. С третьей итерации появляется точка между закрывающей скобкой тела и правой лапой, затем виляние каждые 160 мс при скорости 100% (масштабируется ползунком).
- Виляние **не ограничено четырьмя краткими кадрами**. Оно продолжается всё время, пока глаза остаются `><`, даже при смене поз и сценариев, а при обычном лице исчезает сразу.
- `JoyTailLeft` и `JoyTailRight` (ID 37, 38) оставлены как исторические записи для стабильности ID, но не отвечают за точку. Фронтальное виляние и старое музыкальное виляние со спины не мешают друг другу.
- `I11 Celebrate` теперь длится 8 с и специально держит `F04` до 1,8 с, чтобы хвост успел хорошо повилять.

## Typing и Matrix

- Быстрая реакция лапок: `T00 → T01 → T02 → T01`, по 115 мс на кадр.
- `MatrixRain` в `src/matrix_rain.hpp`: два столбца `23 px` друг к другу вплотную (x=398,421 на холсте 480×320), новый знак появляется снизу после каждого обнаруженного нажатия.
- Старые символы при новом нажатии поднимаются на один слот, с плавным переходом. После прекращения печати поток постепенно уходит вверх и гаснет у отметки `y=54`.
- В `src/japanese_glyphs.hpp` есть 24 плотных векторных знака: 12 кандзи и 12 катакана; `QFont` / fallback не используются.
- Реальные символы ввода и названия клавиш не записываются.

## Геометрия и жирность

- Базовый фронтальный силуэт: **10×31=310 px**, а не 400 px из v0.4.1.
- Для B00–B02 отдельная статическая 11×28=308 px сетка.
- Размер шрифта питомца по умолчанию 43 px и регулируется 30–54 px, жирность 0–100 (по умолчанию 25) меняет вес шрифта и число оттисков от 1 до 7. Фронтальная сетка остаётся фиксированной. Часы и дата используют отдельно настраиваемый шрифт.
- Угол/масштаб перспективы общий для часов, питомца и Matrix. Все три слоя используют общий цвет/яркость и CRT-композит (глоу/пикселизация), а сканлайны, апертурная решётка и движение линии наносится после общей перспективы.

## Как добавлять анимации

См. `docs/ANIMATION_ARCHITECTURE.md`. Добавить неизменяемую позу → обновить статические константы и `kPoseCount` → создать сценарий в `pet_animation.hpp` → добавить его в enum/счётчик действий для ShuffleBag → покрыть тестами → вручную проверить на мониторе. Новое действие источника (не Idle/Music/Typing) требует отдельного определения приоритета. Не меняйте ID уже существующих поз.

### Контракт v0.5.9: никаких изменений Typing/Music ShuffleBag

- Мелкая Idle-жизнь не потребляет элементы очереди Idle: это независимый прозрачный декор между историями.
- Прерванный печатью танец запускается заново после базового Groove, как согласовано в v0.5.8. Не воспроизводить хвост сцен и не сбрасывать ShuffleBag.
- Ноты являются декоративным трёхколоночным потоком примерно в четыре строки под датой, а не анализом аудио. Во время Typing ноты отсутствуют.
- Проверить на конкретном шрифте IBM Plex Mono с пользовательской жирностью и перспективой.

## Gift outcomes v0.6.2

`GiftKind` = `StarFly | ArcFly | BurstSad | BurstCry | Pulse`.
Каждый раз при редком Idle:Fetch следующий вариант извлекается из отдельного
`ShuffleBag(5)`; до завершения цикла варианты не повторяются, на границе циклов
нет соседних дублей. Полный `Fetch` использует фиксированное тело, но новый
сценарий после позы `ReturnCenter`.

| Вариант | Финал | Эмоция |
|---|---|---|
| StarFly | Уже в лапке при входе → перебрасывает в левую лапу (1,6 с) → летит по волне слева направо через весь экран (5,4 с), заметный след из 12 штрихов | `F02` следит → `F07` умиление → `SadSoft` |
| ArcFly | Подарок в лапке → перебрасывает из правой руки в левую (1,65 с) → широкая дуга через весь экран (5,65 с) с тем же шлейфом | `F02` → `F07` → `SadSoft` |
| Pulse | Большая коробочка пульсирует 5,1 с вместе с четырьмя окружающими маленькими звёздами | `F04` → `F17` → F00 |
| BurstSad | Коробка принесена в лапе → вспышка 1,7 с → две волны, 14 лучей, 16 осколков → 3 капли по 1,35 с | `F05` → `SadComic` (длинная выдержка) → `SadSoft` → `F13` → F00 |
| BurstCry | Усиленная вспышка/осколки → 4 последовательные капли по 1,45 с | `F05` → `SadCry` (длинная выдержка) → `SadSoft` → `F13` → F00 |

Слезинка не входит в десятисимвольную сетку и анимируется отдельно по координатам
глаз. Плачущий `SadCry` использует глаза-точки `•` вместо `;`. Глаза у SadComic подняты на 5px, рот опущен на 5px. Никакие `><` глаза
не используются для печали. При новой активности Typing/Music сцена прерывается
полностью без висящих эффектов.

`Frame` содержит `pose`, `durationMs`, необязательный `GiftCue`, горизонтальные координаты перехода, флаг зеркального отражения и признак независимой длительности `absoluteDuration`. `GiftVisual` содержит фазу 0..1, тип подарка, знак эффекта и смещение пока подарок находится в лапе.
Плавность движения обеспечивается GUI-таймером 40мс. Музыкальные 11 сценариев
и их 280мс тайминг не изменены.

## Изменения v0.6.1: читаемость и отладка

- Исправлено ошибочное визуальное направление. Питомец продолжает **уходить спиной**, но возвращается из **левого края вправо**, с двумя глазами `◔`, направленными по ходу движения. Новый вектор смещений -200 → -125 → -55 → 0. Никаких обратно идущих спиной кадров.
- Всё тело сдвинуто на 50px влево в 480×320 холсте; дата, часы, сетки символов и сохранённая калибровка остаются прежними. Вправо больше свободного места для подарка.
- После ухода невидимый кадр теперь 3300мс (100% скорости), а не 1250мс.
- Летящие подарки: 4400–4600мс, только в конце уходят за край холста. Появился **действительно видимый шлейф** из 12 постепенно затухающих штрихов и редких искр, вместо шести почти прозрачных. Во время полёта питомец сначала следит обоими глазами, затем переходит к умилению, после исчезновения подарка — мягкая грусть.
- Взрыв: более длинная вспышка 1600–1750мс. После неё грустное лицо удерживается 1750–1900мс до первых слёз, затем идут 3–4 капли по 1200–1250мс, после последней — отдельная выдержка 1800–2000мс.
- Переход назад в Idle теперь `SadComic/SadCry → SadSoft → F13 (закрытые спокойные глаза) → F00`, а не резкий возврат через открытые сердитые глаза. Выражения и капли не мелькают.
- Правый клик → **Калибровка перспективы / Настройки CRT / Настройки анимации**. В новом окне 4 вкладки: Idle (дыхание и 14 действий), Music (groove и 11 танцев), Typing (с тестовым Matrix), Gifts (5 финалов), Stop Preview. Speed / MPRIS / typing reaction перенесены из CRT-настроек в анимационные. Калибровка и X11 закрепление на рабочих столах не менялись.
- Отладочный предпросмотр запускать через окно либо `crt-clock --animations`. Он не использует реальные нажатые символы и не расходует ShuffleBag. CLI `--preview-gift=...` остаётся.

## Текущая оптимизация v0.6.3

- `src/pet_sprite_cache.hpp`: каждый Unicode-глифовый силуэт 10/11 клеток
  и многослойная жирность готовятся в растровый спрайт **один раз**
  для выбранных шрифта/цвета/толщины/позы/фазы хвоста. Первичная
  растеризация в 2x с гладкой миниатюризацией уменьшает ступеньки
  при промежуточном дробном сдвиге. Движение/дыхание/зеркало применяются
  к готовому спрайту на прежних тиках 40мс, без потери 25FPS.
- `CanvasCache` в `src/main.cpp` отдельно кэширует полную статичную
  CRT-картинку часов/даты/фона. Она пересчитывается при смене минуты,
  настройки или фактическом мерцании времени, не на каждом шаге.
- Для обычных анимаций CRT-свечение питомца считается на нижнем
  фрагменте `480x128`; при высокой дуге, взрыве и перебрасывании
  подарка автоматически используется весь холст 480×320.
- Для печати `MatrixRain::stripImage` рисует лишь 108px справа,
  а не 480px; при смене глаз питомца уже готовый слой Matrix не
  пересоздаётся.
- При `CRT_CLOCK_PROFILE=1` раз в 6 секунд выводятся числа сборок и
  средние миллисекунды на композицию кадра и окно. Без этого
  переменного окружения статистика отключена.
- 8-точечная перспектива и общая композиция X11 остались прежними.
  На целевом XFCE требуется проверить нагрузку CPU и точность
  эффектов после апгрейда; числовое снижение не гарантируется.

**Актуальный набор:** Idle: 15 действий + дыхание. Music: 9 действий +
неизменный Groove. Typing и 5 вариантов Gifts сохранены. Music LookToBeat
и WinkGroove удалены, оба одиночных подмигивания перенесены в Idle.


## v0.6.4: плавный поток слёз и ускоренная перспектива

- Во время `BurstSad` и `BurstCry` длительные выражения лица
  сохраняются. Но во время каждой фазы `TearLeft/TearRight` теперь
  появляется **до четырёх капель на глаз** с разницей по времени;
  второе око начинает на полдоли позже. Капли перекрываются
  и видны одновременно, а не одна слеза за всю фазу.
- Эффект рисуется отдельным векторным слоем и не меняет глазные
  символы, продолжительность плача, Idle-дыхание или позицию глаз.
- Отрисовка перспективы использует предварительно рассчитанную
  обратную карту для четырёх калибруемых трапеций. Одинаковые
  параметры карты переиспользуются между кадрами; при изменении
  восьми точек она пересоздаётся. Static scanlines/grille кэшируются,
  динамическая полоса ripple сохраняется.
- `CRT_CLOCK_LEGACY_PERSPECTIVE=1` позволяет сравнить прежний
  Qt-путь с новым в рамках одного запуска, без изменения настроек.
  Дополнительная профилируемая метрика: `avgWarpMs`.
