# Каталог анимаций CRT Clock v0.5.9

Дата утверждения: 3 ноября 2026. Источник рисунков — утверждённый пользователем полный набор F/H/I/M/B.

**Статус реализации:** первоначальные рисунки F/H/B и исторические ID 0–38 сохранены. Изменения v0.5.7: общая скорость Idle/Music, ровный музыкальный ритм, базовый groove между танцами, три новых танца. Изменения v0.5.8: спокойный рот в groove, постоянно поднимающиеся векторные ноты во время музыки, возобновление прерванных танцев и запрет соседнего повтора между циклами. Изменения v0.5.9: 14 Idle-действий, редкие прогулка и возвращение с подарком, мягкие анимированные черточки и дыхание между действиями, шесть музыкальных нот и более спокойные музыкальные подмигивания. Оценка читаемости на реальном XFCE остаётся обязательной.

## Неприкосновенные правила

- Референс `(づ｡◕‿‿◕｡)づ`. Компактность, положение скобок и лица сохраняются для всех фронтальных поз. Не менять отдельно размер в конкретных кадрах.
- Выражения/лапки/сценарии — **заранее заданные**, один ID = один набор символов/смещений; только выбор сценариев перемешанными циклами может быть случайным.
- Цифра `0` в удивлении, не `O`. Взгляд вправо: **оба глаза** `◔`.
- Моргающий или радостный персонаж может сохранять лицо `(づ｡>‿‿<｡)づ`, `(づ｡0‿‿0｡)づ`, даже если Unicode-глифы визуально сложные.
- Толщину линий менять отдельно от ширины тела. Фактическую ширину / качество глифов проверять на целевом шрифте и после перспективы.
- Музыкальная попа — **поворот спиной**, хвост находится внутри скобок. Не заменять точкой у фронтального персонажа.
- Matrix-поток не использует ячейки питомца, не считывает настоящие клавиши. Две колонки с прилегающими символами движутся снизу вверх и гаснут у часов.

## Позы (зафиксированные ID)

| Диапазон | Кадры | Примечание |
|---|---|---|
| F00–F17 = 0–17 | 18 выражений лица | `F00` — базовая поза |
| H00–H06 = 18–24 | 7 положений лап | `H00` — базовая поза |
| B00–B02 = 25–27 | 3 старые позы со спины | Только Music: TailWag |
| NodDown..BounceDown = 28–33 | Позиционные смещения | Не меняют текстовый силуэт |
| T00–T02 = 34–36 | Печатание | Выделенный отдельный Matrix-поток |
| JoyTailLeft / JoyTailRight = 37–38 | Сохранённые исторические ID | Текущий хвост автоматически реагирует на `><` и не зависит от этих ID |
| ListenNote0–ListenNote3 = 39–42 | Закрытые глаза и ноты | Ноты рисуются отдельно над лицом, без дополнительных ячеек |
| StepLeft / StepRight = 43–44 | Шаг с радостными глазами | Заданные смещения корпуса −9 / +9 px |
| IdleStepLeft / IdleStepRight = 45–46 | Небольшие шаги с обычным лицом | Только для Idle, без изменения старых ID |
| AwayFace..AwayReturn = 47–51 | Уход/возвращение | Отдельные задние силуэты, масштаб 1 → 0,8 → 0,58 → 0,38 → 0,58 → 0,8 → 1 |
| GiftReturn = 52 | Возвращение с маленьким подарком | Векторный ромб возле правой лапы; сетка 10×31 px не меняется |

Между завершёнными idle-сценариями пауза от 6,5 до 14,5 секунды. Все 14 уникальных действий выпадают по одному разу за цикл ShuffleBag, поэтому длинный Fetch появляется редко.

**Постоянная живая Idle-поза:** между историями, только в состоянии Idle, 6 детерминированных фаз (380 мс при скорости 100%) показывают малоконтрастные короткие линии около лап и «дыхание» с вертикальным смещением на ±1 px. При музыке и печати эффект полностью выключен. Положение глаз, рот и десятисимвольная сетка не меняются.

**Исключение для мини-сюжета Fetch:** только добавленные задние позы AwayFace–AwayReturn проходят заранее заданное уменьшение/горизонтальный уход. Это намеренная перспектива персонажа внутри сюжета, а не подстройка ширины Unicode-глифов; все старые позы неизменны.

## Music: 11 действий и базовое покачивание (v0.5.7)

- При воспроизведении MPRIS: **Groove** (8 кадров, 2,24 с) → один случайный танец → Groove → следующий танец.
- Groove: F00 → NodDown → NodUp → F00 → NodDown → NodUp → F00 → F00. Рот остаётся нейтральным: `F17` больше не мелькает по два раза каждый цикл.
- **Каждый кадр каждого музыкального сценария длится 280 мс** при скорости 100%; даже повороты спиной идут под тот же ритм.
- Ни один из 11 танцев не повторяется в пределах цикла `ShuffleBag`; после исчерпания порядок перемешивается заново. Один и тот же танец не может идти подряд даже через границу двух циклов. Печатание прерывает танец, но недоигранное действие будет показано заново перед выбором следующего, без потери позиции в очереди.
- Переходы полностью детерминированы, рандомизирован только порядок действий, а не набор поз и задержек.

**Ноты v0.5.8:** пока MPRIS сообщает `Playing` и не выполняется Typing, над питомцем постоянно появляются шесть векторных нотных знаков с фазами подъёма (цикл из 8 шагов по 220 мс при скорости 100%). Ноты больше не зависят от редкого сценария `EyesClosedNotes` и не используют системный музыкальный Unicode-шрифт: штрихи нарисованы `QPainter`. При отсутствии музыки или во время Typing ноты отсутствуют. Старый `EyesClosedNotes` по-прежнему уникальное действие с закрытыми глазами и четырьмя заранее заданными смещениями, но не управляет общей отрисовкой нот. Проверка реального расположения под перспективой на XFCE обязательна.

**Ползунок скорости:** `pet/autonomous_speed` = 50–180%, по умолчанию 100%. Он меняет интервалы кадра Idle, Music, паузы Idle и фронтальный JoyTail. Не затрагивает `Typing` (115 мс), `MatrixRain`, проверку MPRIS и эффекты CRT.

## Автоматический фронтальный хвост (v0.5.2)

- `src/pet_tail.hpp` проверяет **все позы**, включая Music и Idle, на одновременные радостные глаза `><`. При первом появлении `><` **две итерации анимации по 40 мс** хвост отсутствует. С третьей итерации появляется точка между закрывающей скобкой тела и правой лапой, затем виляние каждые 160 мс при скорости 100% (масштабируется ползунком).
- Виляние **не ограничено четырьмя краткими кадрами**. Оно продолжается всё время, пока глаза остаются `><`, даже при смене поз и сценариев, а при обычном лице исчезает сразу.
- `JoyTailLeft` и `JoyTailRight` (ID 37, 38) оставлены как исторические записи для стабильности ID, но не отвечают за точку. Фронтальное виляние и старое музыкальное виляние со спины не мешают друг другу.
- `I11 Celebrate` по-прежнему длится 4,85 с и специально держит `F04` 1,65 с, чтобы хвост успел хорошо повилять.

## Typing и Matrix

- Быстрая реакция лапок: `T00 → T01 → T02 → T01`, по 115 мс на кадр.
- `MatrixRain` в `src/matrix_rain.hpp`: два столбца `23 px` друг к другу вплотную (x=398,421 на холсте 480×320), новый знак появляется снизу после каждого обнаруженного нажатия.
- Старые символы при новом нажатии поднимаются на один слот, с плавным переходом. После прекращения печати поток постепенно уходит вверх и гаснет у отметки `y=54`.
- В `src/japanese_glyphs.hpp` есть 24 плотных векторных знака: 12 кандзи и 12 катакана; `QFont` / fallback не используются.
- Реальные символы ввода и названия клавиш не записываются.

## Геометрия и жирность

- Базовый фронтальный силуэт: **10×31=310 px**, а не 400 px из v0.4.1.
- Для B00–B02 отдельная статическая 11×28=308 px сетка.
- Размер шрифта питомца по умолчанию 43 px и регулируется 30–54 px, жирность 0–100 (по умолчанию 25) меняет вес шрифта и число оттисков от 1 до 7. Фронтальная сетка остаётся фиксированной. Часы и дата используют отдельно настраиваемый шрифт.
- Угол/масштаб перспективы общий для часов, питомца и Matrix. Все три слоя используют общий цвет/яркость и CRT-композит (глоу/пикселизация), а сканлайны, апертурная решётка и движение линии наносится после общей перспективы.

## Как добавлять анимации

См. `docs/ANIMATION_ARCHITECTURE.md`. Добавить неизменяемую позу → обновить статические константы и `kPoseCount` → создать сценарий в `pet_animation.hpp` → добавить его в enum/счётчик действий для ShuffleBag → покрыть тестами → вручную проверить на мониторе. Новое действие источника (не Idle/Music/Typing) требует отдельного определения приоритета. Не меняйте ID уже существующих поз.

### Контракт v0.5.9: никаких изменений Typing/Music ShuffleBag

- Мелкая Idle-жизнь не потребляет элементы очереди Idle: это независимый прозрачный декор между историями.
- Прерванный печатью танец запускается заново после базового Groove, как согласовано в v0.5.8. Не воспроизводить хвост сцен и не сбрасывать ShuffleBag.
- Шесть нот являются декоративным потоком, а не анализом аудио. Во время Typing ноты отсутствуют.
- Проверить на конкретном шрифте IBM Plex Mono с пользовательской жирностью и перспективой.
